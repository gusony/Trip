# 紐西蘭南島 14 天自駕行李打包清單

> **時間**：9月底–10月初（春季）  
> **天氣**：白天 10–18°C、夜間 0–8°C、山區可能結冰、紫外線極強（UV Index 經常 >8）  
> **行程重點**：冰川飛行、2次跳傘、Roy's Peak 健行（16km/爬升1236m）、Hooker Valley（10.6km）、Dark Sky 夜間觀星（近0°C）、騎馬、螢火蟲洞、海豚船、企鵛觀察  
> **住宿**：部分 Holiday Park（可能無毛巾/盥洗用品）  
> **交通**：已租 SUV，行李空間充裕

---

## ⚠️ NZ 海關 / MPI 生物安全重點（必讀）

1. **所有食物都必須申報** — 不管有沒有開封，不管是不是商業包裝。不申報當場罰 NZ$400。
2. **所有戶外裝備必須申報** — 登山鞋、健行杖、帳篷、露營用品等，無論看起來多乾淨。
3. **入境前徹底清潔所有戶外裝備** — 尤其是鞋底，不能有泥土、種子、植物殘留。建議用刷子 + 稀釋漂白水或戶外裝備專用清潔劑。
4. **禁止攜帶**：新鮮水果/蔬菜、新鮮肉類/魚類、蜂蜜及蜂產品、蛋類。
5. **可以帶但必須申報**：商業包裝、未開封、可常溫保存的食品（固體 ≤10kg、液體 ≤10L、凍乾食品 ≤2kg）。
6. 飛機上吃剩的食物留在飛機上，不要帶下機。
7. 入境前線上填妥 **New Zealand Traveller Declaration**（NZTD）。

### Roy's Peak 特別提醒
- 全程無遮蔽、無補水點、無廁所（僅山腳有）
- 每人至少帶 **2–3L 水**
- 起登時間：清晨 5–6 點出發避開人潮和正午高溫
- 登山杖必備 — 下坡連續陡降對膝蓋負擔極大

### Hooker Valley 特別提醒
- 相對平緩但仍有起伏，登山鞋即可
- 終點 Hooker Lake 風大寒冷，即使晴天也要帶保暖層

## 七、食物 / 補給（入境 NZ 全部必須申報！）

### 建議台灣帶去（商業包裝、未開封、申報）
| 物品 | 說明 |
|------|------|
| 泡麵（無肉塊的） | 素食/海鮮口味較安全 — **含肉塊/肉燥的泡麵可能被沒收** |
| 沖泡式濃湯包 | 粉狀、商業包裝 |
| 三合一咖啡 / 即溶咖啡包 | 商業包裝 OK |
| 茶包 | 一般紅茶/綠茶/烏龍茶包 OK（散裝花草茶不行） |
| 能量棒 / 蛋白棒 | 健行行動糧，未開封商業包裝 |
| 堅果 / 綜合堅果 | 商業包裝、無調味的較安全 |
| 巧克力 | 健行補給 |
| 蘇打餅乾 / 米果 | 車上零食 |

### 不建議／不能帶
- **任何含肉製品**（肉乾、肉鬆、貢丸泡麵）— 極高機率被沒收
- **新鮮水果/蔬菜** — 禁止
- **蜂蜜及蜂產品** — 禁止
- **散裝/手作食品** — 風險高
- **中藥材** — 多數需檢疫處理，建議不要

### 到 NZ 當地買
- 麵包、吐司、果醬、奶油（超市買，很便宜）
- 新鮮蔬菜水果（NZ 超市品質極佳）
- 牛奶、優格、起司（NZ 乳製品世界一流，不用帶）
- 火腿、培根等肉品（當地買）
- 行車補給飲料、運動飲料
