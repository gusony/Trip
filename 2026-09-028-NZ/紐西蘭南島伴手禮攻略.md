## ⚠️ 台灣海關檢疫注意事項

| 類別 | 規定 |
|------|------|
| **蜂蜜/蜂膠** | ✅ 可攜帶（含蜂巢也可）。液體須托運，隨身限100ml。 |
| **蜂膠膠囊/滴劑** | ✅ 可攜帶。 |
| **巧克力/糖果/餅乾** | ✅ 加工食品可攜帶。 |
| **乳製品（奶粉/起司/保久乳）** | ✅ 可攜帶。 |
| **肉類製品** | ❌ 禁止。含肉塊的火鍋湯底、肉乾等不可。 |
| **新鮮水果/蔬菜** | ❌ 禁止。 |
| **動植物活體** | ❌ 禁止。 |
| **木製工藝品** | ⚠️ 需申報檢疫，建議選有檢疫處理證明的。 |
| **免稅額度** | 每人免稅額台幣 2 萬元（含菸酒外物品）。酒類限 1 公升。 |

**入境台灣請走紅線申報檯**，誠實申報就不會被罰。未申報查到罰台幣 3,000 元以上。
